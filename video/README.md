# Видео проекта «Трудяжки · ФСП»

Основной ролик для демонстрации — [запись прототипа, 1:10](6.mp4): профиль кандидата, тест, поиск работодателя, предложение и решение кандидата.

Ролики 1–5 иллюстрируют концепцию и удобство продукта. Ролик 6 записан в моковом прототипе с вымышленными данными. Интерфейс и состав функций могут отличаться от текущего сайта. Видео не подтверждает готовность полной концепции или живых интеграций.

[Галерея с плеерами](index.html) открывается в браузере из локального clone. На GitHub откройте нужный MP4 по ссылке в таблице; если просмотр недоступен, скачайте файл через Raw / Download.

Исходные MP4 сохранены без перекодирования. [Манифест](manifest.json) содержит длительности, размеры и SHA-256 для проверки копии. Все видео входят в обычный Git clone.
