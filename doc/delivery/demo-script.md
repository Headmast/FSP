# Сценарий защиты текущего MVP

**Рабочий лимит: 10 минут вместе с демонстрацией.** Он взят из существующей презентации с оценкой 9–10 минут; официальный тайминг организаторов в доступных источниках не указан. Пользователю задан вопрос о регламенте. До ответа используется этот рабочий лимит, а не утверждение об официальных правилах.

Код приложения и материалов: `34942b532e0ad1643db37e957ccfec30f6d77a6b`. Текст каждого слайда и заметки — [current-mvp-slides.md](current-mvp-slides.md); версия для показа — [HTML](current-mvp-slides.html), [PPTX](current-mvp.pptx), [PDF](current-mvp-slides.pdf).

## Подготовка к живому показу

1. Открыть [постоянный вход](https://llmlove.ru/dreamwork/fsp-demo.html); получить новый адрес из статуса. Проверить `/health/` и `/version/` выбранного выпуска.
2. Сопоставить release SHA с evidence и исходным кодом материалов. Дополнительный коммит документации может иметь другой SHA при неизменённых исходниках приложения; это фиксируется манифестом/отчётом, а не скрывается.
3. Использовать свои новые demo аккаунты либо опубликованные синтетические fixtures. Не запускать seed/reset существующих пользователей во время показа.
4. Открыть материалы локально до старта; браузерные расширения/уведомления убрать. Сохранить резервное видео и PDF доступными без сети.
5. Сначала показать основной путь, затем дополнения. Не тратить время на получение внешних ключей или установку SDK во время защиты.

## Если сеть недоступна

Открыть [резервное демо](assets/current-demo.mp4) либо [полную запись репетиции](assets/timed-rehearsal.mp4). Они записаны на указанном коде с вымышленными данными. Полная запись использует локальную синтетическую речь Milena и настоящий браузерный прогон. Это автоматизированная репетиция с измерением времени; человеческое выступление и реальный пилот отдельно не проверялись.

Для автономного интерактивного просмотра сначала запустить чистый worktree по [инструкции](../development/local-run.md), либо открыть [моковый прототип](../../prototype/index.html) с явным пояснением, что это другой интерфейс. Не выдавать прототип за текущий Django backend.

## Вопросы, на которые отвечать точно

- «Всё делает LLM?» — помощник готовит проверяемые черновики; категория, балл, ранжирование и права вычисляются сервером. AI сейчас мок по разрешению пользователя.
- «Четыре подтверждаемые специализации?» — четыре учебных трека; профессиональный экзамен текущего MVP только iOS/Swift Junior/Middle.
- «Экономит время найма?» — есть переносимое свидетельство и явный зачёт; реальный эффект ещё нужно измерить в QA-002.
- «Почта/ФСП/Telegram/MAX настоящие?» — демонстрационные состояния/адаптеры; живые интеграции отдельно открыты.
- «Удаление отзывает всё?» — пользовательское удаление/анонимизация и отзыв старых грантов ещё не реализованы; снятие публикации сохраняет прежние принятые гранты.
- «Готов к промышленной эксплуатации?» — есть health, выпуск и cron восстановления адреса; постоянный backend, reboot и полный эксплуатационный gate ещё открыты.
