# Контракт адаптера ФСП (внутренний, демо)

Этот документ задаёт потребность приложения, а не описывает неизвестное официальное API. INT-002 требует согласования реального источника и механизма проверки личности.

## Идентичность и согласие

Вход: внешний ID, аутентифицированный владелец Profile, явный флажок fsp-mock-v1 плюс processing-v1. Мок подтверждает только пользовательское действие; принадлежность настоящего FSP ID не доказывается. ID уникален в приложении, не показывается работодателю. Изменить/отвязать может только владелец. Для настоящего провайдера нужны проверяемая авторизация/subject и правила revoke; простого ввода ID недостаточно.

## Ответ fetch(external_id)

source=mock, status=no_history|demo_history; events[] содержит event_id, source, event_name, occurred_on (ISO date), discipline, result, team (boolean), prize (boolean). Набор ограничен нашим демонстрационным словарём. Недоступность сообщает SourceUnavailable; сохраняется status=unavailable без подтверждённых событий/бонуса. Непривязанный профиль имеет not_connected. История привязки хранит дату согласия, версию и время sync.

DEMO-001..999 дают одно событие; нечётный номер — команда/1 место, чётный — личное участие. DEMO-EMPTY даёт пустую историю, DEMO-DOWN — отказ источника. DEMO-000 и остальные строки недопустимы. Результаты мока не трактуются как реальное подтверждение.

## Обновление и права

Связь и замена достижений/кэша рейтинга атомарны; повтор не удваивает события. Недоступность удаляет прошлый бонус, чтобы не показывать устаревшее как актуальное. Отвязка удаляет события, сбрасывает статус/бонус; грейд, тест и старые приглашения не переписываются. Бонус ФСП ограничен 3+2 баллами независимо от числа достижений.

## HTTP

GET /profile/fsp/ — JSON только для владельца: source, status, changes_grade=false, external_id|null, events[]. GET/POST /profile/fsp/link/ — форма external_id/consent; action=unlink отвязывает собственный ID. Ошибка формы/занятого ID — 200, успех — 302. Неверная роль — 403; CSRF обязателен; отсутствие согласия на обработку — 302 consent.
