# Рабочие промпты

Дополнительные промпты для разработки сохраняются как <TASK-ID>-<short-name>.md. В начале указать задачу, цель, исходный SHA, допустимые файлы, входные документы, ожидаемый результат и критерии проверки.

Пример: реализовать MVP-003 в собственной ветке; пользоваться правилами assessments; не менять общие settings без интегратора; приложить тесты порогов и дедлайна, обновить документацию, сделать коммит после проверки.

Не копировать секреты, реальные контакты и конфигурации доступа. Промпты, вызываемые приложением во время работы, находятся в app/assistant, а не здесь. Соответствующий ответ хранится в [responses](../responses/README.md).
