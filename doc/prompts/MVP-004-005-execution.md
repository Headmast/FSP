# Дополнительные указания к реализации

Пользователь: хранить документацию рядом с основным проектом в репозитории; подробный план предварять кратким обзором; добавить проверки и quality gates, оформить цель. Первый шаг — базовый прототип полностью на моках, серверная публикация, описание и коммит. После каждого успешно проверенного этапа делать коммит. Поддержать отдельные worktrees для новых функций из параллельных чатов.

Уточнение от 2026-10-11 по помощнику: «Пока замокай без ключа». Внешний AI не нужен для текущего выпуска; мок должен быть явно обозначен, без секретов и внешних запросов.

Завершить сценарий двух ролей и финальные gates, проверить права в HTML и PDF, конкуренцию, нагрузку, сохранность после перезапуска, откат и чистый worktree. Сохранить фактические результаты и ограничения. Доступы из рабочих чатов использовать только локально/на сервере и не переносить в Git.
