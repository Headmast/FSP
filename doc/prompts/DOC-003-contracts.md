# DOC-003 — полные HTTP контракты и OpenAPI

Активная цель: реализовать все 27 задач, начиная с высоких приоритетов; каждый успешный этап отдельно закоммитить с описанием и проверками.

DOC-003 требует поля всех маршрутов, роли/владельцев, cookie/CSRF или Bearer, HTML/JSON/PDF, фактические статусы/redirect, повторы и ошибки; валидную OpenAPI и воспроизводимые примеры. Не подменять HTML redirect общим 409 или мок живой интеграцией. Проверять спецификацию по реальному коду и запросам; сохранять контрпроверки и ошибки стенда. Общие маршруты/зависимости/публикация — область интегратора.

Во время работы main получил owner dashboard, token V1, затем learning и token V2. Проверенный первый этап интегрирует owner/V1; DOC-003 остаётся IN_PROGRESS до включения последующих маршрутов и повторной полной проверки.
