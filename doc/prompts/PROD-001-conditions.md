# PROD-001 · Условия кандидата

Поручение исходного списка 27: условия кандидата по формату работы, занятости и типам задач; сравнение с потребностью до контакта; совпадение/противоречие/неизвестное, пустое не является совпадением. Формы/фильтры/PDF/объяснения/API/CLI должны использовать одинаковые правила. Не вводить обязательные ожидания зарплаты.

Владелец/область/база — в backlog. Решение: необязательные каталожные списки предпочтений; одна занятость и несколько типов задач в Need. Для задач все указанные работодателем типы должны входить в предпочтения; частичное пересечение обозначает противоречие для уточнения. Категория и рейтинг остаются отдельными. Снимок хранит заявленные условия сторон при отправке; legacy приглашение получает неизвестные предпочтения. Все клиентские записи — prepare + явное подтверждение в браузере.
