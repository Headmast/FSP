# Прямая HTTP публикация прототипа

Задача HTTP-001, владелец: чат «Проверить HTTP без туннеля», ветка mvp/prototype-http. Область изменений: этот отчёт и новый каталог публикации на сервере.

По запросу пользователя 2026-10-11 прототип опубликован без туннеля: http://194.226.126.123/fsp-prototype/.

На digitarium скопировано содержимое ~/fsp-mvp/prototype-current/prototype/ в /srv/digitarium/public/fsp-prototype/. Исходный SHA: 5e40c4a2014658f4056305bf8980245072618c3d, подтверждён внешним запросом version.json. Существующий nginx обслуживает каталог на порту 80; его конфигурация не менялась.

Для совместимости с MIME конфигурацией nginx state.mjs скопирован как state.js, а импорт в опубликованном app.js изменён на ./state.js. Иначе nginx возвращает application/octet-stream и браузер блокирует модуль. Это единственное изменение опубликованного JavaScript относительно исходного коммита.

Проверки: HTTP 200 для страницы, CSS, JavaScript и version.json. scripts/check_prototype.cjs по внешнему HTTP адресу: PASS для профиля, теста, предложения, принятия, открытия контактов, перезагрузки, сброса, отказа и мобильной ширины. Ошибок браузера: 0. Проверка выполнена после завершения SSH сессии.

Публикация независима от туннелей и пользовательских процессов Python; обслуживается существующим nginx. Это статический прототип на моках, а не Django MVP. HTTP не шифрует трафик. Обновления ~/fsp-mvp/prototype-current автоматически сюда не копируются: при новой публикации повторить копирование и адаптацию расширения модуля.

Откат: удалить только /srv/digitarium/public/fsp-prototype/. Остальные страницы сервера и прежние публикации сохраняются.

## Публикация на домене

По уточнению пользователя прототип также опубликован напрямую на https://llmlove.ru/fsp-prototype/. Домен обслуживается отдельным хостингом 31.31.197.16, поэтому публикация на digitarium изначально не создала этот путь. Через существующий FTPS доступ с проверкой сохранённого сертификата загружены только index.html, app.js, state.js, style.css и version.json в /www/llmlove.ru/fsp-prototype. Загруженные байты проверены обратным чтением. Доступы не выводились и не сохранялись в Git.

Путь без завершающего слеша возвращает 301 на путь со слешем. Полный scripts/check_prototype.cjs по HTTPS адресу: PASS, включая принятие, отказ, сохранение состояния и мобильную ширину; ошибок браузера нет. Туннель не используется. Для отката доменной публикации удалить только этот новый каталог на хостинге.
