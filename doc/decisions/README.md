# Принятые решения

Решения основаны на согласованном плане; изменения требуют обновления этого списка и затронутых проверок.

| Решение | Причина |
|---|---|
| Один существующий Headmast/FSP | История, код и документы доступны в любом worktree |
| Прототип полностью на моках первым | Быстро проверить весь путь и публикацию |
| Django и шаблоны | Один backend и простой запуск без отдельного frontend build |
| SQLite | Небольшое demo окружение; границы проверяет нагрузочный gate |
| iOS / Swift, Junior и Middle | Один законченный путь вместо нескольких незавершённых |
| Детерминированные категория и рейтинг | Воспроизводимость результатов и прав |
| Yandex AI Studio | Предыдущий запрос OpenAI с VPS отклонён региональной проверкой |
| Demo email и ФСП моки | Явные согласованные ограничения MVP |
| Временный Cloudflare Tunnel | Доступное HTTPS демо без настройки постоянного домена |

Факт успешного Yandex подключения пока не установлен; решение о провайдере не является результатом проверки.
