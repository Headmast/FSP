# Ответы и результаты рабочих задач

Для каждого сохранённого промпта использовать тот же <TASK-ID>-<short-name>.md. Записывать итог решения, изменения, фактически выполненные проверки, SHA и оставшиеся вопросы. Длинный исходный ответ допустим как приложение; отделять его от принятых решений.

Не включать секреты, реальные персональные данные или вымышленные результаты проверок. По итогам ответа обновить нормативные документы: сам ответ не заменяет архитектуру, контракт или результат QA.
