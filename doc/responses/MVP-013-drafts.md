# MVP-013 — результат

Реализован полный путь черновика на разрешённом моковом провайдере. Новый работодатель задаёт категорию/навыки до создания Need, затем редактирует поля и самостоятельно указывает зарплату. Применение создаёт новую потребность; исходная Need не меняется. Генерация сохраняет только приватный Draft, не профиль/Need/компанию. У кандидата применяется только описание; грейд, контакты, публикация и согласия сохраняются.

Черновики доступны владельцу по отдельной странице и в списке последних 10. Срок применения — 24 часа. Просроченный POST — 410, конфликт с ручным изменением — 409, чужой/неверный ID — 404, невалидные поля — 400, CSRF — 403. Повтор после применения возвращает к результату без второго сохранения. Активный тест запрещает применение/генерацию кандидату; лимит 10 генераций/час не мешает применить уже проверенный черновик. Применение атомарно, источник и результат связаны с Draft.

Исправлен скрытый identifier=None. Мок обозначен в редакторе, цена/контакты компании не выдумываются провайдером. Добавлены формы/миграция Draft и адаптивные textarea. Ошибка провайдера не создаёт Draft/Need и оставляет ссылки на ручные формы.

[Серверные тесты, drift, конкуренция и хеши](../qa/MVP-013-results.json), [локальный браузер](../qa/MVP-013-browser.json), [мобильная форма](../qa/MVP-013-mobile.png). Проверены редактирование/подтверждение, новая компания без предварительной Need, права, CSRF, истечение, повтор, конфликт, лимит и отказ. Восемь параллельных применений создают одну Need; из двух конкурирующих описаний применяется один Draft, второй защищён конфликтом. Первый FAIL теста был неверным ожиданием порядка канонических навыков; исправлено ожидание, нормализатор не менялся.

Для повторения: изолированная DB, migrate/collectstatic, runserver на порту worktree; `node scripts/check_assistant_drafts.cjs http://127.0.0.1:8041`. Browser checker создаёт свои вымышленные аккаунты и принимает только localhost. `python scripts/check_draft_concurrency.py` сам использует временную SQLite. Контракт — в [HTTP документации](../api/contracts.md).

Это локальный успешно проверенный этап. Новый серверный деплой не заявляется; C2 полностью ещё не закрыт до AI-001 и сквозной проверки. Просроченные Draft не удаляются автоматически; удаление/отзыв данных остаются PROD-004. API-спецификация всей системы — DOC-003.

Финальные результаты: 82 теста приложения — PASS (9.588 с), migration drift — PASS, 78 Markdown и согласованность 27 задач — PASS, diff/staged diff — проверены.
