[Контракт продукта](../architecture/gap-challenges.md). Web — `/challenges/`, детали и отправка из принятого предложения. Read API/CLI/MCP дают безопасные структурированные поля без задания/критериев как свободного текста, ответа и комментария. Контакты не открываются этим согласием. Непринятое/чужое/отозванное приглашение не допускает отправку задания.

Отдельный отзыв ответа не закрывает контакты предложения, но прекращает выдачу ответа компании. Он записывается до изменения БД в durable journal с ID и неизменным UUID задания; после restore исходный доступ закрывается повторно, другая строка с переиспользованным числовым ID не затрагивается. Контактный отзыв закрывает и ответ. Очистка/удаление профиля стирает связанные тексты, критерии/ответ/оценку/зачёт и отвязывает кандидата, включая ORM cascade. Архив удаляется через 180 дней. Privacy format 2 блокирует downgrade на код, не очищающий эту модель.
