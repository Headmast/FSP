# MVP-011 — выполнено локально

Поиск и карточка показывают списки совпавших и отсутствующих в самоописании навыков пары. Подтверждение категории берётся из последнего успешного завершённого теста текущей категории с банком/правилами/датой. Если свидетельства нет, это явно указано. Отдельное владение каждым инструментом, опыт и софт-скиллы не приписываются короткому тесту. Состояния FSP not_connected/unavailable обозначают неизвестное; фильтр no_history принимает только no_history.

Карточка использует выбранную собственную потребность и сохраняет query для возврата, чужая/некорректная потребность недоступна. Формула баллов и стабильная сортировка прежние. Пользовательский пилот этим не подменяется.
