# MVP-006 — выполнено локально

Добавлены iOS/Swift, стаж до 600 месяцев, роли/софт-скиллы из словаря, описание до 3000 символов и до 20 записей опыта (проект/организация, роль, месяцы, задачи). Новый пустой слот опыта появляется после сохранения; записи можно редактировать/удалять. Поля опыта и свободный текст видны владельцу, в его PDF и компании после принятия её предложения. Публично показываются только структурированные сведения; они отмечены как самоописание. Подтверждённый грейд форма не меняет.

Профиль и опыт сохраняются одной транзакцией, чужой ID опыта отклоняется, произвольный текст не попадает в публичный HTML/PDF. Миграция добавляет поля с безопасными пустыми значениями, существующие сведения сохраняются.

Обе страницы визуально проверены, текст читается без обрезки. Синтетические PDF остаются в изолированном runtime; реальные данные не публиковались.
