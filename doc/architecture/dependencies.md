# Зависимости и воспроизводимость

Нормативные версии — uv.lock; установка uv sync --locked. На этапе MVP-002 использованы Python 3.13.7 локально, Django 5.2.18, Gunicorn 23.0.0, ReportLab 4.5.1, WhiteNoise 6.12.0. На VPS обнаружен Python 3.13.5; серверная совместимость проверяется при публикации.

ReportLab использует встроенный в репозиторий DejaVuSans; лицензия рядом со шрифтом. Playwright нужен только браузерным проверкам, не приложению. Node нужен для проверки прототипа и browser scripts.

База, venv, секреты и собранная статика исключены из Git и создаются отдельно в каждом worktree.
