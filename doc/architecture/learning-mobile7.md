# Учебный модуль mobile7

Задача MOBILE7-001. Ветка mobile7 основана на main b78a89b. Владелец — чат разработки модуля. Это расширение существующего Django MVP для iOS / Swift; подготовка и экзамен доступны кандидату после подтверждения demo email и согласия на обработку.

## Сценарий

Кандидат выбирает Junior или Middle, изучает одну из четырёх тем Swift, ARC, Async, UI/Data и отмечает урок изученным. Восемь уроков содержат объяснения, пример кода, список для проверки понимания и ссылку на официальный источник.

Самопроверка по всем темам содержит восемь вопросов, по два на область. Практика одной темы содержит четыре вопроса. Независимый банк версии ios-learning-1 содержит 32 новых вопроса (16 на уровень). Порядок вариантов перемешивается; правильный индекс меняется вместе с ним. В учебном банке нет вопросов или ID экзаменационного банка.

Вопросы показываются по одному. Сохранение переносит к первому вопросу без ответа. Кнопка «Сохранить и сделать паузу» записывает текущий выбор и возвращает к маршруту. Переход по номерам и обычным ссылкам сам по себе не сохраняет новый выбор; это объяснено на экране. Сохранённые ответы можно изменить до завершения. Нет таймера или задержки между учебными попытками.

Завершение считает неотвеченные вопросы ошибками, показывает балл, результат по темам, выбранный и правильный ответ, объяснение и ссылки на уроки. Повтор ошибок создаёт новую попытку из неверных и пропущенных вопросов выбранного завершённого результата. Если ошибок нет, повтор не создаётся. На маршруте выводятся слабые области последней общей самопроверки выбранного уровня и последние 20 результатов.

## Данные и границы

LessonProgress хранит кандидата, уровень, тему, версию контента и время отметки. Уникальное ограничение исключает повторную запись одного урока одной версии. Отметка означает самостоятельное подтверждение изучения, а не проверку квалификации.

PracticeSession хранит собственный снимок вопросов и вариантов, ответы, версию, режим check/review, уровень, тему, время и результат по областям. У кандидата одна активная учебная попытка. При повторном старте возвращается существующая; перед началом другой её нужно завершить. При возобновлении существующей попытки это сообщается в интерфейсе. Снимок не меняется при обновлении банка; повтор ошибок использует версию и снимок источника.

Учебный сервис не записывает confirmed_grade, test_score, grade_changed_at, достижения или публикацию профиля. Свидетельства выдаются только существующим модулем assessments. Правила экзамена остаются прежними: 8 вопросов, 15 минут, минимум 6 правильных и минимум один в каждой области, серверный срок и ограничения повторов.

Все попытки и прогресс приватны для владельца; у работодателя нет доступа. Мутации выполняются POST с CSRF. Чужой источник повторения или попытка возвращает 404. Некорректные ID, вопросы и варианты отклоняются. В активном учебном HTML отсутствуют правильные индексы и объяснения. Серверные транзакции и ограничения защищают от дубликатов и потери ответов при одновременных запросах.

Пока действует активная экзаменационная попытка, уроки, старт/продолжение практики, отметки и разборы заблокированы. Истёкшая или завершённая экзаменационная попытка не блокирует обучение. Учебные данные сохраняются и доступны после экзамена.

HTML работает без JavaScript. Семантические формы, radio/fieldset/legend, подписи, видимый фокус, aria-current и текст статуса поддерживают клавиатуру и средства чтения. Локальная браузерная проверка не является сертификацией VoiceOver.

## Запуск и интеграция

В checkout mobile7: uv sync --locked, uv run python app/manage.py migrate, uv run python app/manage.py collectstatic --noinput, uv run python scripts/run_app.py. Адрес — http://127.0.0.1:8057/learning/. Войти своим demo кандидатом или зарегистрировать новый адрес @demo.invalid и подтвердить показанное demo письмо.

Новых зависимостей и изменений settings нет. Требуется миграция assessments/0003_lessonprogress_practicesession.py. Перед интеграцией согласовать общий urls.py и base.html с изменениями других чатов, затем повторить затронутые проверки. Состояние ветки не означает публикацию текущего production MVP.
