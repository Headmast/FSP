## Пользовательский результат

В начале лендинга, прототипа и каждой страницы Django доступны кнопки «Упрощённая версия» и «Настройки доступности». Упрощённая версия использует последовательную компоновку, системный шрифт и контрастный текст, скрывает декоративные иллюстрации. Функции кандидата и работодателя сохраняются.

Настройки: текст 100/125/150/200%, чёрный на белом, белый на чёрном, тёмный на бежевом, увеличенные интервалы, скрытие декора. Они сохраняются в отдельном ключе localStorage, не затрагивают данные прототипа. Если хранилище запрещено, режим работает до перезагрузки.

Озвучивание: локальный голос устройства, скорость 0,75/1/1,25/1,5, страница или выделенный текст, пауза/продолжение/остановка. Автозапуска нет. Значения полей, пароли и скрытые элементы не читаются. Удалённые голоса Web Speech исключены через localService; выбранный голос всегда задаётся явно. При отсутствии русского голоса выбирается другой локальный голос. Если все локальные голоса исчезают, чтение прекращается; интерфейс объясняет, как добавить голос или использовать экранный диктор. Озвучивание элементов по Tab включается явно и не сохраняется между загрузками, чтобы не конфликтовать с VoiceOver.

## Навигация и семантика

Первая ссылка по Tab — переход к содержанию. Формы имеют подписи, область навигации — имя, текущий раздел — aria-current, роль прототипа — aria-pressed. При смене экрана фокус получает заголовок; при повторном сохранении формы фокус возвращается к её кнопке. Сообщения объявляются отдельным role=status, содержимое экрана целиком не является live region. Escape прекращает чтение и закрывает настройки с возвратом фокуса. На странице входа снят autofocus, мешавший доступу к первой ссылке. После ошибки отправки серверной формы фокус получает блок ошибки с role=alert; вложенный список сохраняет нативную семантику. Уменьшенная анимация учитывается по prefers-reduced-motion, системный контраст — по forced-colors.

## Исходники и публикация

Единственный исходник CSS/JS находится в accessibility/. Файлы prototype/accessibility.css и .js — относительные Git symlinks к нему. Django collectstatic копирует их как обычные файлы с manifest-хешами. Лендинг обращается к accessibility/ напрямую, поскольку prototype/ исключён из Jekyll. Архив standalone-прототипа включает обе директории. HTTP сервер прототипа продолжает обслуживать prototype/; symlinks разрешаются внутри release.

Лендинг: [Трудяжки](https://llmlove.ru/dreamwork/). Постоянный вход в приложение и прототип: [открыть демо](https://llmlove.ru/dreamwork/fsp-demo.html). На FTPS переданы только index.html и два файла accessibility/, предыдущие версии сохранены в серверном backup. Публичные файлы по HTTPS совпадают с Git SHA256. Выпуск Django сохраняет ранее опубликованные помощник и API V1, подключения обеих ролей и загрузки клиентского пакета.
