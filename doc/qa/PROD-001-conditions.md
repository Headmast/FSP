Браузер проверял приложение/клиенты 1d2eb6f из чистого clone; финальный QA driver из calling worktree имеет отдельный fingerprint. Исходный код приложения после прогона не изменялся. Первый native CLI driver использовал закрытый HTTP клиент для проверки; исправлен отдельным короткоживущим клиентом и весь реальный CLI/stdio повторён.

Заявленный тип задач — предпочтение, не подтверждённый навык. Empty никогда не совпадает с empty. Частичный выбор задач требует уточнения и не блокирует отправку. Зарплата кандидата не обязательна; прежние 85/10/5 и категория сохраняются. Ручной диктор/человеческий пилот/Linux keyring и живые внешние интеграции NOT_RUN; MCLI-013 в полном составе не закрывается этим этапом.
