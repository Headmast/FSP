## Воспроизведение

Из checkout mobile7 выполнить uv sync --locked, migrate и collectstatic, затем запустить scripts/run_app.py. Проверка браузера принимает http://127.0.0.1:8057 и создаёт только собственные синтетические аккаунты @demo.invalid в локальной базе. Нужны Playwright и Chromium; в текущем запуске использован bundled Node/Playwright. Скрипт конкурентности создаёт и удаляет отдельную временную SQLite, не трогает базу приложения.

Команды серверных и браузерных проверок находятся в таблице. Браузерный запуск: NODE_PATH=<каталог bundled node_modules> <bundled node> scripts/check_learning.cjs http://127.0.0.1:8057. Отчёты новых запусков сохраняются в .runtime/qa; в doc/qa скопированы результаты этой приёмки.

## Ограничения приёмки

Эта проверка относится к отдельной ветке. Production публикация, интеграция в main, native Android/Flutter UI, JSON API, прокторинг, реальный AI и проверка VoiceOver не выполнялись. Отдельное подтверждение категории использует прежний экзаменационный сервис. Учебные оценки не служат свидетельством квалификации. Исторические gates общего выпуска не переназначались на этот модуль.
