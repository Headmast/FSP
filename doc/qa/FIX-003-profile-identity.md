## Воспроизведение

На исходном прототипе localhost:8043: заполнить имя «ДЖ Проверка», город Самара, навыки Swift/Core Data, не нажимать «Сохранить профиль», перейти к тесту Middle. Обработчик переключает view и перерисовывает форму без чтения введённых полей. Они остаются в DOM, но не попадают в state.profile. После теста поиск остаётся на Junior: собственный Middle отсутствует, видна Мария Демо. Имя Марии принадлежит отдельному fixture; чужие данные backend здесь не подменяются.

Новая браузерная проверка на исходной версии завершилась ожидаемым FAIL (отсутствует имя кандидата на результате). На исправленной версии — PASS.

## Исправление

Поля читаются и сохраняются перед переходом из профиля, переключением роли, подтверждением demo email и показом ответа помощника. HTML validation остаётся обязательной. Результат показывает имя state.profile; поиск открывает его подтверждённую категорию; карточки обозначают «Ваш профиль кандидата» и «Вымышленный кандидат для примера». Адрес регистрации берётся из сохранённого профиля.
