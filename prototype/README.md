# Прототип обратного найма на моках

Запуск из корня: `python3 -m http.server 8010 --bind 127.0.0.1 --directory prototype`.
Открыть http://127.0.0.1:8010. Внешние библиотеки, backend и API не используются.

Сценарий: сохранить профиль → тест (ответы 1, 2, 3, 4) → категория Junior → роль работодателя → профиль Алексея → предложение → роль кандидата → предложения → принять → роль работодателя → профиль → вымышленные контакты.

После сброса повторить с отклонением: контакты скрыты. Сброс очищает только состояние этого приложения. Перезагрузка сохраняет данные в localStorage. Весь доступ имитируется: это не реальная авторизация. Банк ответов открыт в исходниках намеренно, только для прототипа.

Подробности и приёмка: [спецификация](../doc/prototype/specification.md).
