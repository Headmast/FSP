# Трудяжки — статический сайт команды

- index.html — открытая страница команды.
- strategy-71c4.html — рабочий отчёт, не связанный с главной страницей и помеченный noindex, nofollow.
- style.css — общие адаптивные стили.

Сборка и библиотеки не нужны. Для локального просмотра откройте index.html в браузере.

## GitHub Pages

В настройках репозитория откройте Settings → Pages и выберите источник Deploy from a branch, ветку main, папку root. Сайт будет доступен по адресу вида https://<владелец>.github.io/<репозиторий>/.

Приватный репозиторий не делает опубликованный сайт приватным. Доступ к Pages из приватного репозитория зависит от тарифа GitHub; опубликованная страница обычно открыта всем. Отчёт скрыт от индексации, но не защищён паролем.

## Индексация

Страница отчёта содержит мета-теги noindex, nofollow. Файл robots.txt разрешает обход сайта, чтобы роботы могли прочитать эти мета-теги. Это настройка поисковой индексации, а не контроль доступа.

## MVP обратного найма

Планируется отдельное приложение для iOS разработчиков: профиль, тест, категория, предложение работодателя и контакты после согласия. Первый этап — опубликованный прототип полностью на моках.

Начните с [документации](doc/README.md), [цели](doc/goal.md) и [плана](doc/plan/implementation.md). Приложение и прототип пока не реализованы.

Документация и инструменты исключены из стандартной Jekyll сборки через _config.yml. При публикации без Jekyll нужен отдельный артефакт только с файлами сайта; фактический режим Pages ещё не проверен.
